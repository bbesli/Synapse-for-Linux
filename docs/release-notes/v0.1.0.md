The first public release of **Synapse for Linux**: an independent, open-source app, inspired by
Razer Synapse, for configuring Razer headsets on Linux.

> Synapse for Linux is a community project. It is not affiliated with, endorsed or supported by
> Razer Inc. and it contains no Razer code, logos or files. We just want the spirit of Synapse
> to live on on Linux too.

### Supported devices

| Device | USB ID | Status |
|---|---|---|
| Razer BlackShark V2 HyperSpeed (2.4 GHz dongle) | `1532:0565` | ✅ tested on hardware |
| Razer BlackShark V2 HyperSpeed (USB cable) | `1532:056E` | 🟡 untested |
| Razer BlackShark V2 HyperSpeed (variant) | `1532:0566` | 🧪 experimental |

### Highlights

- Equalizer presets and a 10-band custom EQ editor; settings are stored in the headset itself
- Mic monitoring (sidetone) with 16 levels, auto power-off, dongle light, Bluetooth call blocking
- Battery level in the window and the tray, with low-battery notifications
- Optional PipeWire/WebRTC microphone noise suppression
- `synapsectl` command-line tool; English and Turkish interface

### Install (x86_64, glibc 2.35+)

```bash
curl -fsSL https://github.com/bbesli/Synapse-for-Linux/releases/latest/download/synapse-linux-x86_64.tar.gz | tar xz
cd synapse-linux-x86_64 && ./install.sh
```

Arch Linux / CachyOS users can also build a package: `cd packaging/arch && makepkg -si`.
Check the download with `sha256sum -c SHA256SUMS`.
